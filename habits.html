Habits (15113 phone app)

A small daily habits tracker built with Expo and Expo Router. Data stays on the device in AsyncStorage—no accounts or network required.

Features

  • Home: List habits, mark today done/undone, delete with confirmation, pull to refresh
  • Stats: Today’s completion rate, rolling 7-day completion across habits, per-habit streaks
  • Add habit: Modal with name and a preset emoji picker
  • Per habit: Current streak and a 7-day completion grid (local calendar dates)

For the full product and data model, see SPEC.md in the project repository.

Requirements

  • Node.js (LTS recommended)
  • For simulators: Xcode (iOS) and/or Android Studio (Android), or run on a physical device with Expo Go

Setup

npm install npx expo start

Then press i for iOS, a for Android, or scan the QR code in Expo Go.

Other scripts:

npm run lint # ESLint (Expo config) npm run ios # expo start --ios npm run android # expo start --android
